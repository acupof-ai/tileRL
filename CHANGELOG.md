What caught it was not the reversal but the magnitude against a **recorded** number: `TILERL_NCOLS=1` *is* the shipped path by construction, and the shipped path is 8.92; a flag cannot make the code it disables 3.8× faster than that code. Still slower, because ptxas vectorized the staged words into two `LDS.128` — **swapping LDG for LDS one-for-one** and leaving the per-row ratio at **1 load : 4 HFMA2**, then adding the stage (8 LDG + 16 STS + 2 barriers) on top. **The binding quantity is loads per FMA**, and every failed candidate preserved it: reorder (PIPELINE 0.99×), memory space (SMEM 0.67×), block shape (`n_partition`), accumulator chain, register budget (`min_blocks` 1.00×).
